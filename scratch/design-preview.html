Why no colour

Colour dates. Brutalist yellow, dark salmon, indigo — every accent divides opinion. Pure monochrome is the ground Vercel, Framer, Anthropic, and Linear (early) all settled on. It reads as premium and confident, and lets one hero accent be added later once the product finds its voice.

Why system fonts

SF Pro on macOS, Segoe UI Variable on Windows 11, Roboto Flex on Android — the native stacks are actually gorgeous now, load instantly, and match the OS so the product feels installed rather than "webby". No CDN dependency, no font-flash on slow connections.

What we're dropping

Thick 2px ink borders, 4px hard-offset shadows, cursive display faces, uppercase-everywhere headings, wavy border filters, and the yellow/salmon/blue accent debate itself. Only the primary action and current page state get contrast — the rest reads as ambient.

Ship it?

Three files change: tailwind.config.ts, globals.css, layout.tsx. Every page picks it up automatically. If you don't love it, one git checkout puts everything back.
